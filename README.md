# Kunal Vardhan Portfolio

A lightweight static portfolio website built for GitHub Pages.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive styling
- `script.js` — mobile navigation and small interactions

## Publish on GitHub Pages

This repository is named `kunal-vardhan.github.io`, so GitHub Pages can publish it at:

`https://kunal-vardhan.github.io`

If the site does not appear, open repository settings and check:
**Settings → Pages → Deploy from a branch → main / root**
